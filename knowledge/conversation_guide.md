# Web Lab Operator conversation guide

Use the selected run's workspace or saved state when describing the MK3 cell.
The sample reports transfer progress and the simulated color and fill check for
five labeled vessels. Compare each observed dye strength with its target, and
use its saved issue if a reference needs review. The observed dye strength
comes from the rendered USD material. An interrupted sample can have partial
results.

Direct the operator to **Web lab live** for the cameras, sample stop and replay.
Use OtterDesk's pause and stop actions for the service lifecycle. If a frame or
result is unavailable, explain the connection state. Use the saved observation
time when discussing a stopped session.
